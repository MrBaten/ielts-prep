# IELTS Prep Tracker

An installable study app for IELTS Academic that works offline: a daily routine checklist, 1,620 flashcards with spaced repetition, a match game, spelling and meaning drills, a timed Writing editor, Speaking timers, mock-test band tracking and a mistake log.

**Open it:** https://mrbaten.github.io/ielts-prep/

Open the link once while online, then use your browser's **Install app** / **Add to Home screen**. After that it runs without internet. Progress is saved on the device; use *Progress → Copy backup / Restore* to move it between devices.

**Online:** add your own OpenRouter or Anthropic API key in *Progress → AI settings* to get essay marking, speaking feedback and new drills. The key stays on your device only. Speak-to-type uses the browser's speech recognition.

**Offline:** everything else keeps working, including drills you generated earlier (they are saved automatically).
