# IELTS Prep Tracker

An installable study app for IELTS Academic that works offline: a daily routine checklist, 620 flashcards with spaced repetition, a match game, spelling and meaning drills, a timed Writing editor, Speaking timers, mock-test band tracking and a mistake log.

**Open it:** https://mrbaten.github.io/ielts-prep/

Open the link once while online, then use your browser's **Install app** / **Add to Home screen**. After that it runs without internet. Progress is saved on the device; use *Progress → Copy backup / Restore* to move it between devices.

AI features (essay marking, speaking feedback, generated drills) run only in the Claude version of the app.
